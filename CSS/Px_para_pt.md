# Diferença percentual de pixel para points

|  de | para  | razão | points  |
|-----|-------|-------|---------| 
| 1px | 1pt   |  3/4  |  0.75pt |
| 1pt | 1px   |  4/3  |  1.33px |

## Cálculo

Para poder transformar 1pt em 1px e vice versa, multiplicamos pela sua razão. A fórmula é da respectiva maneira:

> de 1pt para 1px:  
> Xpt * (4/3)

> de 1px para 1pt:  
> Xpx * (3/4)
