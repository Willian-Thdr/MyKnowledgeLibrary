## Observações importantes

- **HTML** é uma linguagem de marcação, e **CSS** é uma linguagem de folhas de estilo; não são linguagens de programação convencionais.
- **SQL** é uma linguagem especializada em consultar e manipular bancos de dados relacionais.
- **SQLite, PostgreSQL e MySQL** são sistemas de gerenciamento de bancos de dados, não linguagens.
- **React, FastAPI, Django, Flask, Express e Laravel** são bibliotecas ou frameworks, não linguagens.
- **Unity, Unreal Engine e Godot** são engines de desenvolvimento de jogos.
- Um projeto pode utilizar várias linguagens, mas isso não é obrigatório. Algumas aplicações são desenvolvidas principalmente com uma única linguagem.
- As tecnologias complementares variam conforme os requisitos, o tamanho do projeto, a plataforma e a experiência da equipe.

## Sugestão de ordem de estudo

1. Python — lógica, estruturas de dados, funções, módulos e orientação a objetos.
2. SQL e SQLite — persistência, consultas, relacionamentos e transações.
3. HTML, CSS e JavaScript — fundamentos do desenvolvimento web.
4. Git — versionamento e organização de projetos.
5. APIs e backend — comunicação entre aplicações, servidores e bancos de dados.
6. Especialização — inteligência artificial, jogos, aplicações desktop, dispositivos móveis ou sistemas embarcados.
